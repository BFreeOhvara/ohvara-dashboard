# App Review notes (P928 text, kept here so it lives in git)

Apple's API has no field for these, so they are pasted once into App Store Connect →
the app → App Review Information → Notes. They carry over from one version to the next;
paste again only when this file changes. Sign-in logins are NOT in git: portal → Settings →
Team tools → App Review logins → Reset, then paste both into App Review Information.
Don't reset them while Apple is reviewing.
